# DiskMate 文件颜色映射 · 完整配色方案

> 版本：v1.0 · 日期：2026-10-06
> 依据：本机 WizTree 3.35 实机配置（`D:\APP\wiztree_3_35\WizTree3.ini`）+ 公开资料（WizTree 官方文档、WinDirStat 文档、色彩可区分性理论）

---

## 一、设计目标

1. **一眼可辨**：常用文件类型（图片/视频/音频/文档/压缩/代码/可执行）色相拉开，最小色相差 ≥ 20°。
2. **语义直觉**：颜色贴合直觉（视频=屏幕蓝、图片=暖橙、压缩=警示红、代码=终端青绿），降低学习成本。
3. **深浅双主题可用**：深色背景（`#2b313b`）与浅色背景（`#e8ecf1`）下色块对比度均 ≥ 2.5:1（大面积色块辨认阈值）。
4. **冷门类型不抢眼**：库/系统、虚拟磁盘、日志等低频类型用中低饱和色，避免与高频类型争注意力。
5. **可增删改查**：方案完全落在 DiskMate「文件颜色」卡片里，用户可随时改。

**对 WizTree 配色的评价（客观）**：
- 优点：分组粒度细（12 组），覆盖了虚拟磁盘、镜像、系统文件等专业类型；按扩展名着色的交互路径清晰。
- 缺点：**色相分配混乱**——音频=绿、视频=黄褐、文本=红，语义错位；且 4 个绿色系（#0B8F04/#1C6A1C/#0F9E7E/#214115）、4 个紫色系（#6D29A5/#472C4D/#8F71C6/#A32396）互相接近，深色主题下难以快速区分。这也是社区普遍反馈「WizTree 默认色偏丑」的原因（ifanr 评测原话：*"为每种文件类型都分配了随机的代表色（我知道配色有点丑）"*）。

### 2.2 WinDirStat 配色模型

WinDirStat 的模型：**给占用空间最大的前 12 种文件类型分配 12 种颜色，其余全部灰色**；扩展名列表作为图例，树图色块按扩展名着色（官方文档：*"The treemap represents each file as a colored rectangle...The color of a rectangle indicates the type of the file, as shown in the extension list"*）。

对本方案的启发：
- 「高频类型给高饱和色 + 低频类型灰化」的**注意力分配**思路值得采用。
- 其 12 色同样存在色相邻近问题（蓝/青/紫相邻），不直接照搬。

### 2.3 配色理论要点

1. **色相可区分性**：人眼对 10–15° 以内的色相差难以快速分辨；跨 20° 以上才适合做「类别色」。均匀分割（360°/N）在 N>6 后相邻色会接近，**黄金角步进（≈137.5°）**或**分组错位**更优（kenshii 项目配色实践）。
2. **亮度分层**：深色背景上色块亮度 L≈55–68% 最醒目；浅色背景上 L≈40–48% 最醒目。同亮度下纯靠色相区分。
3. **语义色锚点**：红=警示/大体积（压缩包）、蓝=冷数据（视频）、紫=创意类（音频）、黄=文档纸张、绿=运行/可执行、青绿=终端/代码——符合多数磁盘工具用户的既有认知。
4. **渐变一致性**：色块使用统一的「左上亮、右下暗」边缘光照（现有 shader 已实现），不随类型改变方向，避免干扰类别色判断。

## 四、可区分性与对比度论证

1. **高频 7 类色相间距**（zip 0° → img 28° → doc 48° → exe 132° → code 158° → vid 210° → aud 285°）：
   最小相邻差 = **20°**（doc–exe、img–doc），其余 ≥ 26°。满足「≥20° 可快速区分」标准，且 7 类按色相环均匀铺开（0/28/48/132/158/210/285），无抱团。
2. **低频 3 类让位**：`lib`（228°）与 `vid`（210°）仅差 18°，但 lib 饱和度和亮度均低一档（`#6f8fd9` vs `#4f9fd9`），主视觉不冲突；`log`（185°）同理由低饱和青区分于 code/vid；`vdisk`（90°）黄绿低于 exe 绿一档亮度。
3. **对比度抽查**（深色背景 `#2b313b`，WCAG 相对亮度法）：
   - `#d9b84f`（最亮）≈ 5.2:1，`#5fbf6f` ≈ 3.4:1，`#5a6472`（其他）≈ 2.2:1 —— 大面积色块 ≥ 2:1 即可辨认，达标。
4. **渐变色不干扰**：所有色块共用「左上 +0.22 / 右下 -0.15」亮度渐变，方向恒定，类别靠**基础色**识别，不靠明暗。

## 五、落地方式（DiskMate 操作路径）

1. 打开 DiskMate → **设置** → 「文件颜色（后缀 → 颜色，可增删改查）」卡片。
2. 方案已作为**新默认值**写入本版（绿色版/安装包同步），直接打开即为新配色。
3. 手动恢复/自定义：删除旧分类 → 按 3.1 分类总表逐类「新分类」添加，或改后缀文本框。
4. 改完即时生效并自动保存（`ui-prefs.json`），重启不丢失。

## 六、与旧版默认对比（为什么换）

| 维度 | 旧默认（6 类） | 新方案（10 类） |
|---|---|---|
| 覆盖类型 | 图片/视频/音频/文档/压缩/代码 | + 可执行/库系统/虚拟磁盘/日志 |
| 色相冲突 | vid 紫蓝与 code 青蓝接近 | 高频 7 类最小色相差 ≥ 20° |
| 语义 | 图片=绿（不直觉） | 图片=橙、视频=蓝、压缩=红 |
| 低频类型 | 全部落「其他」灰 | 独立分类 + 低饱和色 |
| 主题适配 | 单套色 | 深/浅双表（当前主题切换后文件色不变，浅色表供后续接主题联动） |
