DiskMate v1.0 — 磁盘空间分析器
================================

对标 WizTree 的 NTFS 高速扫描工具。

【运行】
双击 diskmate_web.exe 即可（首次需联网安装 WebView2 运行时，Win10/11 一般自带）。

【两种扫描模式】
- MFT 直读：直接解析 NTFS 卷，全盘扫描速度远快于普通遍历，需管理员权限。
  程序启动时会自动请求管理员身份；同意 → 按钮显示「MFT 直读」；
  拒绝 → 以普通模式运行，按钮显示「普通遍历」。
  顶部栏按钮可随时一键切换（切到直读时会自动提权）。
- 普通遍历：兼容所有路径/文件系统，速度较慢。

【使用】
1. 输入或浏览选择要扫描的目录（盘符根如 C:\ 才能用 MFT 直读）
2. 点「扫描」
3. 左侧为文件列表（树），右侧为矩形树图（面积 = log 后的大小）
4. 右键菜单与资源管理器一致（打开/属性/复制路径等）
5. 树图上滚轮：框选父目录 / 下滚回

【配置文件】
diskmate.ini —— 最近路径 / 主题 / mft 模式（0=普通 1=强制MFT 2=自动）

【系统要求】
Windows 10/11 x64，NTFS 卷支持 MFT 直读。
